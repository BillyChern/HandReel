Third-party licences for the interactive viewer (viewer/client/index.html)

The viewer is the static web client of Viser 1.1.1, built by Viser's authors as one file. Viser is released under
the Apache License 2.0; its full text is the first entry below. The client bundles code from the npm packages
listed after it, at the versions pinned in the client's package-lock.json. This list is the runtime dependency
closure of the client's source imports (type-only packages left out), so it may name packages that the
minified bundle does not contain. Each entry reproduces the licence and notice files published in that package
version; where a package publishes none, the standard text of its declared licence is given with the copyright
holder named in its package.json, and the entry says so.

The client also carries one image that is not code: its default environment map, which lights the 3D scene when a
recording sets none (the recordings on this page set none). Viser 1.1.1 names this default "city" and maps it to
the file potsdamer_platz_1k.jpg (src/viser/_scene_api.py and src/viser/_assets/hdri/ at tag v1.1.1). That file
name is the Poly Haven asset "Potsdamer Platz" by Greg Zaal (polyhaven.com/a/potsdamer_platz). Poly Haven
licenses all of its assets under CC0 1.0 (polyhaven.com/license), which asks for no attribution; the credit is
given here as a courtesy. Checked on 2026-11-20 from Viser's source tree and Poly Haven's asset record. The
client file is packed, so the embedded image itself was not compared byte for byte with Poly Haven's download.
